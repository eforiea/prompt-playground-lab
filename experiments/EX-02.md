# Day 3 - Context Window & Memory

## Experiment 1 - Real Memory or Context?

### System

```text
You are a helpful assistant.
```

### Conversation

**User**

```text
My favorite animal is penguin.
```

**Assistant**

```text
...
```

**User**

```text
What is my favorite animal?
```

Then clear the conversation history and ask only:

```text
What is my favorite animal?
```

### Questions

- Did the answer change?
- Why?

### Observation

After clearing the history, the model did not know the answer beforehand, yet it provides the correct response.

### Hypothesis

Since the model is stateless, it likely won't be able to access the information we previously provided after the history is cleared, and will state that it doesn't know.

### Conclusion

The models do not have memory and can only respond based on the provided context.

## Experiment 2 - Updating Information

### Conversation

**User**

```text
My favorite color is blue.
```

**User**

```text
Actually my favorite color is red.
```

**User**

```text
What is my favorite color?
```

### Questions

- Which color does the model choose?
- Does it prefer the latest information?

### Observation

Model chose the newer color (red).

### Hypothesis

Model probably needs to choose the newest color.

### Conclusion

The model can update its previous information using the latest data provided to it and return a response based on that.

## Experiment 3 - Multiple Facts

### Conversation

**User**

```text
My name is Alex. I live in Canada. My favorite food is pizza. I have two dogs. I love Linux.
```

Then ask:

```text
Where do I live?
```

```text
What is my favorite food?
```

```text
How many dogs do I have?
```

### Questions

- Did the model remember all the facts correctly?
- Did any information get mixed up?

### Observation

The model answered all the questions correctly.

### Hypothesis

The model should likely be able to answer the questions based on the information we provided to it.

### Conclusion

If we provide the model with the necessary context, it can respond based on it.

## Experiment 4 - Removing Context

### Steps

1. Have a conversation with the model.
2. Clear the conversation history.
3. Ask the previous questions again.

### Questions

- Could the model still answer correctly?
- What changed after clearing the history?

### Observation
The model failed to provide accurate and correct answers to the questions.

### Hypothesis

The model likely cannot provide an answer.

### Conclusion

The model does not have built-in memory to store information; therefore, to maintain a continuous conversation, we must also send previous information to the model.
