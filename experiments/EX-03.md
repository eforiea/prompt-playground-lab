# Day 4 – Zero-shot, One-shot & Few-shot Prompting

## Objective

Understand how providing examples affects the quality and consistency of an LLM's responses.

---

# Theory

## Zero-shot Prompting

Definition:

A prompt where the model receives only the task, without any examples.

Use Cases:

- Simple questions
- General knowledge
- Basic text generation

---

## One-shot Prompting

Definition:

A prompt that includes exactly one example before the actual task.

Use Cases:

- Teaching the desired format
- Improving consistency
- Translation
- Classification

---

## Few-shot Prompting

Definition:

A prompt that provides multiple examples before asking the model to perform the task.

Use Cases:

- Complex formatting
- Classification
- Style imitation
- Pattern learning

---

# Experiment 1 — Zero-shot

## Prompt

```text
Translate to French: Hello
```

### Model Response

```
Bonjour
```

### Observation

- Correct translation? yes
- Output format: no format

### Hypothesis

The model likely just translates the word and returns its French equivalent.

### Conclusion

If the model's output structure and format are not specified, the output is displayed in a standard, simple format.

---

# Experiment 2 — One-shot

## Prompt

```text
English: Cat    French: Chat
English: Hello  French:
```

### Model Response

```
Bonjour
```

### Observation

The model's response did not change and remained the same as before.

### Hypothesis

The model's response should likely change compared to before and resemble the example.

### Conclusion

The model might still fail to adhere to the desired format, even if an example is provided.

---

# Experiment 3 — Few-shot

## Prompt

```text
English: Dog | French: Chien

English: Bird | French: Oiseau

English: Apple | French: Pomme

English: Hello | French:
```

### Model Response

```
English: Hello | French: Bonjour
```

### Observation

- More consistent? yes
- Better formatting? yes

### Hypothesis

The model might still not adhere to the desired format.

### Conclusion

The more examples we provide for the model, the more likely it is to adhere to the desired output format.
