# Day 5 – Chain of Thought & Structured Prompting

## Objective

Observe how prompt structure influences response quality.

---

# Theory

## Chain of Thought

Definition:

Encouraging the model to reason through a problem step by step before producing the final answer.

Purpose:

- Better reasoning
- More reliable solutions
- Reduced logical mistakes

---

## Structured Prompting

Definition:

Requesting the output in a predefined structure such as JSON or Markdown.

Purpose:

- Easier parsing
- Better integration with applications
- Consistent output format

---

# Experiment 1 — Normal Prompt

## Prompt

```text
Solve this problem: A store sells a notebook for $8. John buys 5 notebooks. How much does he pay?
```

### Response

```
John buys 5 notebooks, each costing $8.

To find the total cost:  
**Total = Number of notebooks × Price per notebook**  
**Total = 5 × 8 = 40**

So, John pays **$40**.

**Answer: $40**
 
```

### Observation

- Correct? yes
- Easy to read? normal

---

# Experiment 2 — Step-by-step Prompt

## Prompt

```text
Solve this problem. Think step by step before giving the final answer. A store sells a notebook for $8. John buys 5 notebooks. How much does he pay?
```

### Response

```
To solve the problem:

1. **Identify the price per notebook**: The notebook costs $8.
2. **Determine the number of notebooks bought**: John buys 5 notebooks.
3. **Calculate the total cost**: Multiply the price per notebook by the number of notebooks.

$$
\text{Total cost} = 8 \times 5 = 40
$$

So, John pays **$40**.

**Final Answer: $40**
 
```

### Observation

- Better explanation? yes
- Same final answer? yes
- More reliable? yes

# Experiment 3 — Structured Output

## Prompt

```text
Answer only in JSON. Question: What is SQL Injection?
```

### Response

```json
{
  "SQL Injection": "SQL Injection is a code injection technique used by attackers to exploit vulnerabilities in an application's database layer. It occurs when untrusted input is concatenated directly into SQL queries without proper sanitization or parameterization, allowing attackers to manipulate the query's logic. This can lead to unauthorized access, data theft, data modification, deletion of data, or even complete database compromise. Prevention methods include using prepared statements (parameterized queries), input validation, stored procedures, and implementing least-privilege database accounts."
}
```

### Observation

- Valid JSON? yes
- Easy to parse? yes
- Suitable for applications? yes

# Conclusion

Questions:

- Did prompt structure affect quality? yes
- Why do AI Agents often require structured outputs?
```
AI Agents often require structured outputs because they need to reliably process and act on the information.

Structured formats (like JSON) make the output:

Predictable — consistent fields and formats.
Machine-readable — easy for other tools/APIs to parse.
Actionable — lets the agent trigger the correct next step automatically.
Less ambiguous — reduces errors caused by free-form text.
```
- Which style would be easiest for automation? Structured output (e.g., JSON)
